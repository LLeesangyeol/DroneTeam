# UI설명

## 연결 및 스트림 상태
- stream start시 연결 상태 확인
- target ip : 127.0.0.1
- target port : 50300
- 연결시 ArUco 마크 탐지

## 네트워크 설정
- open socket 클릭시 설정
- ip : 127.0.0.1
- send port 50200
- listen port 50100

## 실시간 데이터링 
- 실시간 드론 데이터

## 제어 알고리즘 파트
- 자동 착륙 알고리즘 
    - on : ArUco 마크 탐지시 자동 착륙
    - off : ArUco 마크만 탐지

## 비행 모드 변경
- 클릭시 모드 설정 가능

## 수동 명령
- 설정 후 명령 전송시 드론 움직임
