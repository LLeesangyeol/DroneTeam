# 🚁 Universal Drone Auto-Landing System (by. 임건수)

이 프로젝트는 기존의 기본적인 드론 제어 시스템을 기반으로, **사용자 편의성(UI/UX), 안정성(Stability), 그리고 정밀 제어 기능**을 대폭 강화한 **통합 지상 관제 시스템(GCS)**입니다.

Python(Tkinter)과 OpenCV, FFmpeg를 활용하여 드론의 영상을 실시간으로 수신하고, ArUco 마커를 인식하여 **정밀 자동 착륙** 및 **수동 제어**를 수행합니다.

---

## 🛠️ 주요 변경 및 개선 사항 (Update Log)

초기 프로토타입(`realFinal.py`)에서 다음과 같은 기능들이 추가 및 개선되었습니다.

### 1. 🎨 UI/UX 전면 개편 (Modern Dark Theme)

- **다크 모드 적용:** 눈의 피로를 줄이고 전문적인 느낌을 주는 다크 테마(Charcoal/Cyan)를 적용했습니다.
- **레이아웃 확장:** 기존의 작은 창(`600x950`)에서 **`580x920`**으로 확장하여 시인성을 높였습니다.
- **탭(Tab) 분리:** 한 화면에 모든 기능이 몰려있던 것을 **[비행 제어], [시스템 로그], [환경 설정]** 탭으로 분리하여 조작 편의성을 극대화했습니다.
- **상단 정보 바:** 연결 상태, 배터리 전압, FPS 정보를 상단에 고정하여 실시간 모니터링이 가능하도록 개선했습니다.

### 2. 🕹️ 조작 기능 강화 (Advanced Control)

- **대각선 이동 추가:** 기존의 4방향(상하좌우) 제어에 **대각선(↖, ↗, ↙, ↘) 버튼**을 추가하여 3축 동시 제어(X, Z축 복합 이동)가 가능해졌습니다.
- **좌표 이동 시스템:** `POS` 모드를 활용하여 특정 X, Y, Z, Yaw 좌표로 정밀하게 이동하는 패널을 추가했습니다.
- **아이콘형 버튼:** 텍스트 대신 화살표 아이콘을 사용하여 직관적인 조작 환경을 구축했습니다.

### 3. 📹 영상 처리 프로세스 최적화 (Stability)

- **FFmpeg 파이프라인 개선:** 영상 수신 중지 시 프로그램이 멈추는(Freezing) 현상을 해결하기 위해 **프로세스 강제 종료(Kill) 및 비동기 처리 로직**을 추가했습니다.
- **OpenCV 호환성 해결:** 최신 OpenCV 버전에서 삭제된 `estimatePoseSingleMarkers` 함수를 대체하여, **`cv2.solvePnP`**를 이용한 3D 좌표 계산 로직으로 업그레이드했습니다.
- **자동 리사이징:** 수신된 영상 소스가 어떤 해상도이든 GUI에 맞춰 **640x480**으로 자동 변환되도록 FFmpeg 옵션을 조정했습니다.

### 4. 📉 자동 착륙 알고리즘 고도화 (Wide Funnel)

- **재이륙 버그 수정:** 자동 착륙 후 다시 이륙했을 때, 이전 고도값이 초기화되지 않아 바로 착륙 모드로 진입하던 치명적인 오류를 수정했습니다. (변수 리셋 로직 추가)
- **시각적 가이드:** 화면상에 **Safety Zone(안전 구역)** 원을 그려, 드론이 허용 범위 내에 있는지 시각적으로 확인할 수 있게 했습니다.

### 5. 📝 시스템 로그 시스템 (Logging)

- **상세 로그 기록:** 단순 콘솔 출력이 아닌, GUI 내 **[시스템 로그]** 탭에 `[연-월-일 시:분:초]` 형식으로 모든 이벤트(연결, 모드 변경, 수동 조작 등)를 기록합니다.
- **연결 상태 모니터링:** 드론과의 UDP 통신 연결/해제 여부를 실시간으로 감지하여 로그에 남깁니다.
